# M0-169 license and release identity evidence

Status: in progress, implementation slice recorded 2026-09-18.

ADR-0010 records the recommended GPL-3.0-or-later direction, the provisional
workspace declaration, alternative choices, and the required owner/legal gate
for the final application license, public name, application ID, repository
identity, and managed signing key. It also records the independent
implementation/provenance boundary and the separate QtWebEngine/Chromium and
asset notice obligations.

No license file, public release signature, or final branding claim is invented
until the owner closes that decision.
