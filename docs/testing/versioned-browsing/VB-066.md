# VB-066 — Explicit structural export from a linked transient branch

Status: verified for the test-feature structural export transaction. This does not qualify production clean branching, page-enriched export, cookie transfer, or the final native release campaign.

On 2026-10-07, the application gained a bounded, one-use preview and confirmation for a published clean child and its exact normal-profile source owner. Preview projects the child window's ordered tabs and selection into a new structural manifest and fresh durable commit identity; it does not submit a write. The preview exposes only the destination profile and page count to the child-window confirmation dialog. Confirmation rechecks both native owners, lineage, window and tab identities, source targets, safe-GET proofs, and application revisions before submitting the prepared commit to the normal profile. Cancellation, timeout, stale owners, changed child pages and wrong destinations consume or refuse the preview without copying child storage.

The child `commit` route is intercepted before ordinary command dispatch and accepts only an explicit window-scope structural commit. It cannot fall through to private-profile persistence. The disclosure says that the durable capture can contain URLs, tab order and basic page settings, but no cookies, page bodies, grants or live authenticated branch. The child profile remains off-record and the normal owner receives only the structural DTO. Page-enriched export remains separately gated by VB-067.

Focused evidence: `cargo test -p ferric-browser-application --features unqualified-clean-branch-test --locked --offline versioning::branch::tests --quiet` passed 15/15, including cancel, wrong destination, unrelated private owner, closed child lineage, two-tab publication and reopening the normal store after child destruction without resurrecting a live branch. `cargo check -p ferric-browser-engine-qt --features unqualified-clean-branch-test --locked --offline --quiet` passed. The default production capability remains disabled. Native dialog and restart journeys belong to final qualification and are not claimed by these focused checks.
