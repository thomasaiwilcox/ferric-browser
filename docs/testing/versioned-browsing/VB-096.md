# VB-096 — Current-window restore replacement and consent

Status: blocked. This safety requirement was separated from VB-024 on 2026-10-07. Default restore opens a new normal-profile window and preserves the source; `--into=current` still returns `retention-unavailable` without mutating it. A structural URL checkpoint cannot preserve unknown unsaved web application state. VB-033 must first qualify exact per-view live retention and activity absence; then this slice needs consent, failure rollback and native lifecycle evidence. No new behavior test was run as part of the split.
