# VB-097 — Ordinary viewless profile download to durable ledger

Status: blocked. This independent ordinary-download requirement was separated from exact permitted MHTML Save Page routing in VB-044 on 2026-10-07. The authored public MV3 extension candidate SIGSEGVs at activation on tested Qt 6.10.3, 6.11.2 and isolated 6.140.0 RC runtimes. Public `QWebEnginePage::download()` succeeds but has a non-null page and cannot serve as the witness. The integrated exact-profile `page()==nullptr` request, terminal callback, installed bytes and durable ledger row therefore remain unproven. The extension probe is opt-in only while its crash is unresolved; production archive capture remains disabled pending VB-057. See VB-044 for the detailed experiments and negative evidence.
