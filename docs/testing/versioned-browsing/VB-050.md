## Implemented surface

- The native page-capture route now records Rust-clocked archive start and
  completion timestamps from the exact claimed save and correlated terminal
  download, plus capture-relative monotonic offsets for sidecar and archive
  intervals. Wall-clock facts remain for provenance; elapsed-time validation
  uses the monotonic intervals.
- Before starting the archive save, QML requests a bounded frame-tree sidecar
  using a Rust-issued operation nonce, a route fingerprint, and a
  capture-local fingerprint. The helper checks the captured root route and
  admits only same-origin HTTP(S) child frames; the Rust parser independently
  checks size, schema, frame topology, category coverage, the challenge, and
  the current authorized operation.
- Each participating document is stamped in its isolated ApplicationWorld
  and re-probed after the asynchronous tree walk. A same-URL reload therefore
  invalidates the combined sidecar rather than relying on URL equality as a
  document-generation signal.
- A valid sidecar is installed as a separate immutable object by the bounded
  file-only worker. It is not mixed into the MHTML archive bytes or logged.
- Rust checks that the sidecar's requested category set exactly matches the
  categories authorized for this one-use capture. Missing an opted-in
  category or adding an unrequested category prevents sidecar publication.
- Archive and semantic-page fidelity are independent. A collector timeout,
  parse failure, or sidecar install failure does not discard a successfully
  installed archive; page coverage is `unavailable` in that case.
- The manifest records separate archive and sidecar intervals and bounded
  category counts plus QtWebEngine, Chromium base/security-patch, and Qt
  platform facts obtained from public runtime APIs. Invalid or unavailable
  runtime facts remain explicitly `unavailable`; they are never copied from
  the page or QML result. A capture-scoped `MutationObserver` retains only a boolean,
  disconnects after the first mutation, and is probed after archive completion.
  Evidence distinguishes `observed-stable`, `observed-changed`, and
  `not-observed`; changed or unavailable evidence forces partial page fidelity.
  Stable means only that no mutation was observed in admitted documents during
  the interval. It is not an atomicity or complete-render certificate. Observer
  state expires after two minutes if normal capture teardown cannot probe it.
- The manifest validates monotonic offsets as capture-local, bounded values;
  component intervals must match their wall-clock counterparts and the archive
  must start no earlier than sidecar collection completion.
- If a captured frame handle or its isolated-world challenge changes between
  the sidecar and archive completion, publication is cancelled instead of
  pairing data from different documents.
- The page sidecar category list includes VB-055's separately consented,
  bounded media metadata under the same one-use page-capture operation. It
  stores no source URL; source comparison uses a fingerprint only.
- QML fixtures now exercise both mutation outcomes, assert changed document
  text never appears in the sidecar, and reload the same URL between the
  sidecar and archive completion. Manifest validation refuses to label
  `not-observed` or `observed-changed` page evidence complete.
- A focused Rust fidelity case covers unavailable sidecars, changed or
  unobserved mutation state, truncated category coverage, and the sole
  complete condition: an installed sidecar with observed-stable evidence and
  no truncated categories. The consent path also rejects a sidecar whose
  requested category set differs from the exact one-use options, including a
  missing opted-in category. Runtime fingerprint syntax and length bounds
  also have a focused Rust regression, and an application publication fixture
  asserts that the trusted fingerprint survives in the committed manifest.
- Isolated archive provenance labels expose mutation evidence as a warning:
  unavailable, observed change, or no change observed with an explicit
  non-atomicity caveat.
