## Behavior

The shared command dispatcher parses a closed `VersioningCommand` and captures its window, optional tab/document target and source in a redacted `VersioningRequest`. The core reducer validates the captured owner and emits a typed request effect without changing its revision or durable state. The runtime does not publish that request as an IPC event. `BrowserApplication` owns admission and replaces the request with a typed status response or a payload-free capability refusal; it never invokes native or storage work for an unavailable operation. The current public Qt backend returns production-disabled status. Merge apply, general cookie reconciliation, retained work, archive restore and other unqualified operations remain gated with specific reasons.

The thin Qt adapter presents the application response. Its checkpoint scheduler ignores a status-only request, and the IPC status query returns bounded capability fields. `Main.qml` remains composition-only. This is execution-path wiring for later vertical slices, not a native versioning implementation or a production capability certificate.
