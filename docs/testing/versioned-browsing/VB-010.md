## Behavior

`versioning::model` captures one exact tab target or the ordered membership of one window, with the logical application revision, active-tab selection, window/profile identity and a supplied native profile-instance binding. Member storage is private and immutable. Window admission rejects empty, non-live, inconsistent, mixed-profile or more-than-128-member scopes; it does not silently narrow a request. Context selection returns `ContextUnavailable` until its separate integration slice, VB-028.

Delayed page results must name an admitted target and present the same live application/profile-instance binding. They reject closed owners, moved tabs, replaced documents and stale generations while allowing unrelated focus changes. The native binding is supplied by a trusted future application/adapter owner registry; core does not discover or attest Qt object identity itself. Neither this token nor runtime tab IDs are durable authority. Structural snapshots may still use their admitted logical input after unrelated state changes; the delayed-page validation is deliberately stronger.

## Privacy and ownership review

The resolver is pure Qt-independent code and copies only runtime identity tokens, not page text, URLs, editable values or cookies. No new command, storage object, native API or context capture is enabled. A native callback cannot substitute the currently selected tab for its admitted target.
