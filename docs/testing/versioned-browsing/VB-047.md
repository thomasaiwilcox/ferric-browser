## Behaviour

`VersionedPageState.js` generates a closed ApplicationWorld program for one top-document observation. Its request carries a nonce, exact expected HTTP(S) origin and route, route and capture fingerprints, and node/candidate/time budgets. The program refuses changed origin/route, bounds traversal to at most 4,096 elements, 64 candidates, 50 ms between traversal checks, 512 positions and a 256 KiB encoded result. It reports top and eligible nested scroll offsets, plus opt-in simple `details` and `select` state. Candidate id/name/context hints are SHA-256 fingerprints of bounded inputs, never raw selectors; non-finite positions, detached nodes, ambiguous selected options and unsupported data are excluded. The result is schema-1 JSON with explicit category coverage and exclusions. It does not collect editable values or traverse frames/shadow trees in this slice.

The existing ADR-0014 explicit scroll-target state is never read or written by the collector. The script neither retains DOM references after the synchronous call nor asks the page to scroll, focus, submit or play media. Rust's checked `PageStateSidecar` parser admits the synthetic native output only after schema, size, semantic and exact nonce/origin/route/capture checks. This is not an integrated production capture path and does not enable any capability flag.

## Privacy and ownership boundary

The script is used only against a disposable off-record synthetic WebEngine view in this evidence. The one emitted JSON fixture marker contains fixed synthetic geometry and hashes, no real profile data. A hash is only a candidate hint and may be guessable for low-entropy attributes; it is not authority to identify or mutate a live element. Production collection still needs an owner-bound capture operation, late-callback rejection, storage/publication policy and native qualification in later slices.

## Remaining boundary

The collector excludes frames, shadow trees, editable values, selections and media; those are separate slices. It deliberately does not claim an absolute 50 ms wall-clock bound on browser style/layout calls; it checks elapsed time at every traversal iteration. A future integrated path must refuse stale document owners and revalidate candidate matches before any restore action. Production capability flags remain false.
