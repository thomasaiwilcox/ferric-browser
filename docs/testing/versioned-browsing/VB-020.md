## Behavior

`versioning::objects` creates only fixed, typed-ID-derived paths beneath a private normal-profile state root. It verifies a canonical random profile UUID, private directory ownership/mode, refuses existing symlink entries and operation-directory reuse, and creates an exact `capture.bin` target with mode 0600 and exclusive creation. Completed-file opening uses no-follow and nonblocking flags and checks descriptor metadata, owner, mode, regular-file type and link count. No page title, URL, cookie name or raw path becomes an output component. The module does not publish objects or commits.

`StagedCapture::stream_capture` checks the completed file through 16-KiB chunks against a caller-supplied byte cap and optional exact byte count from native completion. It refuses empty, known oversized, or native-size-mismatched files before giving bytes to the sink, bounds each subsequent read, retries interrupted reads, and detects size changes or path/inode substitution at completion. The sink receives partial bytes if a later check fails and must discard that state. `open_capture` also compares the opened descriptor's inode with the path that was checked.

`install_object` copies only those bounded bytes to an exclusive private temporary file, incrementally hashes them with pinned RustCrypto `sha2` 0.10.9, checks an optional expected digest, and fsyncs the file. It installs at a lowercase SHA-256-derived profile-local path using a no-overwrite hard-link followed by unlinking the temporary name, then fsyncs both affected directories. A pre-existing path is reused only after owner/mode/type/link-count checks and an exact size-and-byte comparison; a symlink or mismatching file is rejected without overwrite. Directory ancestors are synced before a successful install is returned. On error, the temporary file is removed best-effort; an interrupted operation may leave an unreferenced object, never a visible commit. VB-021 owns recovery and SQLite publication.

Dependency review: the pinned crate is dual `MIT OR Apache-2.0`, with no optional assembly feature enabled. The older RustSec advisory concerns 0.9.7's AVX2 backend and is patched in 0.9.8 or later. Sources: [crate documentation](https://docs.rs/sha2/0.10.9/sha2/), [RustSec package record](https://rustsec.org/packages/sha2.html), [advisory](https://rustsec.org/advisories/RUSTSEC-2021-0100.html). This is a hash for object identity, not encryption or authenticity against a malicious same-UID actor.

Threat boundary: web-controlled capture data cannot supply a filesystem destination. The normal-profile worker must still bind the root and profile owner before calling this module. A malicious same-UID process is outside the proposal's threat model; the checks are not a general defence against concurrent replacement by that actor.
