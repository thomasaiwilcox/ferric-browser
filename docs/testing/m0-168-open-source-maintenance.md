# M0-168 open-source maintenance evidence

Status: in progress, implementation slice recorded 2026-09-18.

`CONTRIBUTING.md` documents the Cargo/Qt checks, registry ownership, FFI and
UI-thread boundaries, Wayland reproduction, PR evidence, and privacy rules.
`CODE_OF_CONDUCT.md` establishes the collaboration boundary, while
`SECURITY.md` keeps vulnerability reports private until an actual channel is
published.

`docs/MAINTENANCE.md` records branch/tag, semantic-versioning, IPC negotiation,
deprecation, ownership, and support-window discipline. `docs/PROVENANCE.md`
records the independent implementation boundary, source/asset notice policy,
and the fact that current names and namespaces are not yet cleared.

The selected application license and a real private security contact remain
owner/release decisions; this slice deliberately does not invent either.
