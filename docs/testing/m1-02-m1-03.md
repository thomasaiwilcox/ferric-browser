## Limitations

The full V1 command catalog, typed flag parsing, persistent
history/bookmark/quickmark completion, bounded memory-only private history
with opt-in completion suggestions, asynchronous query revisions and
privacy filtering, complete native Qt event-pair/IME handling,
key-up/autorepeat/dead-key/AltGr coverage, rich-editor focus behavior,
screen-reader focus evidence, and QML accessible overlays are later
dependencies. The binding handoff is
implemented for the current default commands but is not yet a full native
input qualification.

IPC response envelope follow-up: `command.execute` and typed `action.execute`
responses now include a bounded `command_context` object containing source,
operation ID, count, selected window/tab/profile IDs, profile label, privacy,
window context, requested profile/context, open target, and invocation source.
Direct IPC requests default to `ipc`; launcher-forwarded CLI requests preserve
`cli` through the typed envelope. Structured command
failures carry the same context while continuing to omit URLs, titles, page
content, arguments, and credentials. The context is captured before effects
are reduced so it describes the invocation target even when the command opens
or closes tabs.

## Repeat and macro follow-up

The shared registry now contains `repeat`, `cancel`, `macro-record`,
`macro-stop`, and `macro-play`; `.` is generated as the normal-mode repeat
binding. Repeat stores only eligible non-sensitive browser commands. Macro
registers are memory-only, accept one alphanumeric register, record the same
eligible command class, and enforce maximum nesting depth 8. CLI and typed IPC
command paths use the same validation as interactive commands. Normal-mode
`q` + register starts/stops recording and `@` + register replays through that
same executor; both gestures are bounded by the shared chord timeout and are
cancelled by Escape without forwarding either key to the page.

Live Wayland evidence: recording `tab-open` in register `a`, playing it, then
querying tabs produced the expected additional tab; `tab-open` followed by
`repeat` produced one more tab. Strict workspace Clippy and focused tests pass.
