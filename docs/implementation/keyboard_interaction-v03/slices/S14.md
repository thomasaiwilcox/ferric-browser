## Implementation order
1. Implement exact weak scope lease acquisition before releasing source candidate maps; allow only one page-target session per window.
2. Collect visible descendants excluding scope root, with same open-root/frame boundary; handle empty or replaced scopes without whole-page fallback.
3. Connect explicit Set scroll target through existing setter unchanged; track scope/config/document invalidation.
4. Expose local scoped action handoff under C05 and test cancellation/GC/late callbacks and focus/scroll independence.

## Do not do
No persistent last-region selector, duplicate scroller policy, multiple live unrelated hint registries or remote ability to provide a scope handle.

- **T037 — Scoped hints and scroll independence:** Descendants only, no empty-scope full-page fallback; hint/search actions do not change focus/scroll; explicit Set scroll target uses existing axis/invalidation semantics. Evidence: webengine-fixture.
- **T044 — Teardown and weak-reference stress:** 1000 start/cancel cycles and forced GC leave no growing retained maps/listeners/observers; legitimate connected weak targets stay usable in qualified engine. Evidence: webengine-fixture, performance.
