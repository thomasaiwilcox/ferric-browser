## Implementation order
1. Add typed Region/Surface facets and explicit family grammar with caps/minimums from C13; default f remains unchanged.
2. Collect structural/named panels and actual visual surfaces using shared eligibility; deduplicate existing registry identities.
3. Derive action capabilities in Rust. Do not equate selecting a panel with click/focus/scroll changes.
4. Test cross-origin exterior, closed-root boundaries, hidden buffers and generic-div floods; show unavailable semantic actions honestly.

## Do not do
No second DOM ID space, size-only generic-div inference, fake focus by tabindex mutation or uninspected iframe child claims.
