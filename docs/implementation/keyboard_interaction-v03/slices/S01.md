## Implementation order
1. Add self-contained fixtures for open shadow button/input, slots, clipping/overlays, same-origin frame replacement and actual focus refusal; instrument known fixture effect counters only.
2. Exercise production collector, fresh validator and final focus/click end-to-end, not substitutes. Run the suspected shadow-root case at baseline before changing the implementation.
3. Integrate fixture discovery into the real WebEngine runner and native suite as appropriate. Pin any framework assets with licence metadata; label emulated behaviours ACE-like/Bootstrap-like rather than full compatibility.
4. Capture initial discovery/refresh/overlay samples and a task-by-failure-mode matrix. Real-site rows start not-run.

## Do not do
Do not pre-fix production code, patch the fixture to force an expected failure, count source assertions as activation evidence or add live network dependencies to CI.

## Tests and evidence
- **T002 — Open shadow roots: discovery through final action:** An open-root button activates once and input focus settles on the retained input; demonstrate baseline failure or record non-reproduction. Evidence: webengine-fixture, native-qt-offscreen.
- **T003 — Nested slots and composed ancestry:** Slotted/open-root descendants share clipping and hit rules; inert/disabled ancestors and malformed/deep ancestry reject safely. Evidence: webengine-fixture.
- **T004 — Same-origin frame projection and replacement:** Nested frame borders, scroll offsets and clipping are respected; a reused frame path with a new document invalidates the old target. Evidence: webengine-fixture.
- **T005 — Hidden, detached and newly covered controls:** Hidden, opacity-zero ordinary, disabled, inert, detached, adopted or covered targets do not activate; replacement with same text does not inherit selection. Evidence: webengine-fixture.
- **T006 — Viewport overflow regression preservation:** Existing YouTube body/root zero-height, containment and partial clipping regressions still pass; no site-specific branch. Evidence: webengine-fixture.
- **T008 — Actual focus rather than optimistic success:** Final focus checks the intended deep active element; a handler moving focus or refusing focus does not produce false focus-success. Evidence: webengine-fixture.
- **T043 — Comparable performance samples:** 10 warm-ups and 100 measured samples; 500 at three zoom levels plus 1000/5000; stage timings and raw p95 calculation; specified common-case regression threshold. Evidence: performance.
