## Implementation order
1. Rerun stage timings against S01 with C17 sampling and workload identity. Publish raw timing data and platform details before any optimisation.
2. Apply only supported measured changes: per-pass link indexing, coalescing, bounded traversal, stable overlay diff, or a separately justified versioned runtime installation.
3. Check truncated/unsupported responses, 1000-session retained-resource counts and connected weak-target GC behaviour.
4. Compare common-case and stress p95; regressions trigger investigation, not test-budget edits. Keep any no-benefit refactor out of this slice.

## Do not do
No unmeasured caching, permanent polling, promise of interruptible CSS/layout, removal of fresh checks, architecture rewrite or global benchmark claims.

## Tests and evidence
- **T019 — Script extraction parity and isolation:** Manifest/hash/package parity, legacy facade behaviour, ApplicationWorld isolation, resource missing/version mismatch and exception failure paths all pass. Evidence: pure-unit, webengine-fixture.
- **T020 — Operation/map lifetime and handoff:** No hint-map destruction before callback; acquire destination lease before source cleanup; weak refs, observers and callbacks terminate exactly once. Evidence: webengine-fixture.
- **T033 — Selector/traversal resource stress:** Large/dynamic roots and expensive selectors expose bounded/truncated status; caps do not pretend synchronous CSS evaluation can be interrupted. Evidence: webengine-fixture, performance.
- **T043 — Comparable performance samples:** 10 warm-ups and 100 measured samples; 500 at three zoom levels plus 1000/5000; stage timings and raw p95 calculation; specified common-case regression threshold. Evidence: performance.
- **T044 — Teardown and weak-reference stress:** 1000 start/cancel cycles and forced GC leave no growing retained maps/listeners/observers; legitimate connected weak targets stay usable in qualified engine. Evidence: webengine-fixture, performance.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.

Use the existing repository command for each suite, verified in S00. Run all applicable C22 gates; never claim `cargo test` alone exercises the native suite. Before handoff, review exact target/owner/epoch checks; local provenance; effect cardinality; cleanup and privacy; defaults and documentation. Do not advance a dependent capability through a failed security contract. Environment-only missing evidence uses `implemented_unqualified` or `blocked_environment`, never `complete`.
