## Implementation order
1. Add off-by-default hints.proxy_targets through typed metadata/validation. Document validated as an explicit opt-in, not a selector permission.
2. Represent exact visible editor and unique eligible ACE-like receiver as a paired target inside the existing registry; revalidate both and verify actual focus.
3. Implement/test Bootstrap-like visible label/control association separately as LabelControl with checked-state semantics, not as a textarea or external-editor target.
4. Prove no arbitrary invisible/password/file/read-only/inert or replaced receiver becomes a target. Preserve automatic/transient/locked Insert transitions.
5. Run native entry/composition fixtures and record actual-framework evidence separately from structural emulation.

## Do not do
No CSS/disabled/tabindex mutation, class-only allowlist, guessed new receiver on activation, automatic Locked Insert or rich-document extraction.
