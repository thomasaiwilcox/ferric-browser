## Implementation order
1. Extract only the touched shared composed-parent/hit/clipping/interactability primitives. Preserve body/root propagation and separate pointer, focus and scroll policies.
2. Route collector, fresh validator and final focus/click through the compatible primitives. Re-resolve the exact original objects; correct open-root descent and actual-focus success only where tests justify.
3. Test same-URL sibling and covered/replaced controls. Do not use equivalent-URL discovery deduplication as final hit authority.
4. Remove input-value/secret fallback from target naming used by affected paths; add payload byte bounds and plain-text presentation regression coverage.
5. Keep API changes minimal and retain callback/map lifetime until action completion; document proved repair versus safe refactoring.

## Do not do
No global hidden-input exceptions, whole-script rewrite, new element registry, native click transport, site-specific fix or relaxed stale-target check.

## Tests and evidence
- **T002 — Open shadow roots: discovery through final action:** An open-root button activates once and input focus settles on the retained input; demonstrate baseline failure or record non-reproduction. Evidence: webengine-fixture, native-qt-offscreen.
- **T003 — Nested slots and composed ancestry:** Slotted/open-root descendants share clipping and hit rules; inert/disabled ancestors and malformed/deep ancestry reject safely. Evidence: webengine-fixture.
- **T004 — Same-origin frame projection and replacement:** Nested frame borders, scroll offsets and clipping are respected; a reused frame path with a new document invalidates the old target. Evidence: webengine-fixture.
- **T005 — Hidden, detached and newly covered controls:** Hidden, opacity-zero ordinary, disabled, inert, detached, adopted or covered targets do not activate; replacement with same text does not inherit selection. Evidence: webengine-fixture.
- **T006 — Viewport overflow regression preservation:** Existing YouTube body/root zero-height, containment and partial clipping regressions still pass; no site-specific branch. Evidence: webengine-fixture.
- **T007 — Same-URL sibling is not final authority:** Discovery deduplication cannot authorise pointer delivery to a covering same-URL sibling. Semantic action retains the exact selected object. Evidence: webengine-fixture.
- **T008 — Actual focus rather than optimistic success:** Final focus checks the intended deep active element; a handler moving focus or refusing focus does not produce false focus-success. Evidence: webengine-fixture.
- **T009 — Typed candidate payload and safe labels:** Reject malformed IDs/geometry/extra authority fields; no control value, password, secret hidden buffer or HTML executes/leaks through labels. Evidence: pure-unit, webengine-fixture.
- **T020 — Operation/map lifetime and handoff:** No hint-map destruction before callback; acquire destination lease before source cleanup; weak refs, observers and callbacks terminate exactly once. Evidence: webengine-fixture.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.
