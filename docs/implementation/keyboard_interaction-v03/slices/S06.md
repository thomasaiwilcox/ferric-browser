## Implementation order
1. Move touched helper/operation source to ordinary versioned browser-owned JS resources; keep the facade and current lifecycle/API behaviour.
2. Use structured/JSON-encoded arguments; register assets in the actual current resource/hash/package path identified by S00.
3. Run source/behaviour parity, missing-resource/version/exception tests and existing full interaction fixtures.
4. Defer permanent runtime installation or caching to measured S17 work; do not introduce a second document registry.

## Do not do
No broad JS rewrite, world-ID change, production DevTools/web-channel dependency, remote code loading or premature persistent runtime.
