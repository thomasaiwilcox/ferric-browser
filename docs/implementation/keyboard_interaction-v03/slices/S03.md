## Implementation order
1. Add a closed intent-to-transport decision and non-serialisable local interaction permit using existing invocation provenance. Keep semantic/URL/focus defaults unchanged.
2. Extend hint grammar for pointer selection internally and validate no rapid/first/index combinations. Do not enable the UI action before S04 completes.
3. Add explicit ADR-0013 amendment for physical local Hint/Search palette handoff only; document negative CLI/IPC/userscript/macro/repeat/generic executor paths.
4. Define session/owner/config revision and consumed-request handling shared by later pointer/scoped actions. No page payload may choose an arbitrary capability.

## Do not do
Do not approve general action discovery or remote coordinate injection, introduce a second pointer adapter or expose serialisable authority tokens.
