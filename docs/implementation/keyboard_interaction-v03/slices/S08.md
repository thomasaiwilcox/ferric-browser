## Implementation order
1. Publish and apply the new settings atomically, then integrate the synchronous ownership decision before /, ?, : and other QML Normal special cases.
2. Reuse accepted/forwarded/entry gesture bookkeeping and original Qt events. Do not classify delayed renderer copies as new physical input.
3. Apply reserved controls and pending browser chain/count policy exactly; reconfiguration cancels chains but never replays their text.
4. Extend binding-explain and both windows with real ownership provenance. Exercise native presses/repeats/releases, overlapping keys, layouts/composition and recovery.

## Do not do
No secondary QML event filter, asynchronous DOM query per key, artificial key synthesis, wildcard forwarding or stored-event delivery to a new tab.

## Tests and evidence
- **T021 — Mixed key parser and effective policy:** Reject multi-key/modifier-only/duplicate/reserved entries and more than 64; preserve existing token conventions; exact replace/inherit precedence and atomic errors. Evidence: pure-unit.
- **T022 — Early QML-special key ownership:** Configured /, ?, f and Ctrl+f reach page once; : and recovery controls remain browser-owned; unconfigured sites retain baseline. Evidence: native-qt-offscreen, native-wayland.
- **T023 — Count/keychain semantics:** Mapped first g/digit can go to page; active browser chain/count retains continuations; misses/timeouts/config changes never replay buffered tokens to page. Evidence: pure-unit, native-qt-offscreen.
- **T024 — Physical gesture regression:** Native keydown/up, repeats, overlaps, entry-key isolation, lost releases, delayed WebEngine copies and epoch changes never double-dispatch or become a new browser command. Evidence: native-qt-offscreen.
- **T025 — Escape, mode labels and primary/secondary parity:** Existing Ctrl+v/Ctrl+Shift+v/;v/i/I and recovery/emergency semantics plus both window status/help surfaces remain correct. Evidence: qml-component, native-qt-offscreen.
- **T027 — Configuration/focus change during held input:** New gesture gets new effective route/config; an existing gesture keeps its routing owner; no manual redirect to an old or newly active DOM recipient. Evidence: native-qt-offscreen.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.
- **T055 — Registry/CLI/IPC/resource documentation parity:** New arguments/settings/help and invalid combinations agree across registry/codecs/runtime; local-only paths reject remotely; manifests/hashes/docs regenerate cleanly. Evidence: pure-unit.
