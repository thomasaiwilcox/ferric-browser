## Implementation order
1. Evaluate ACE, CodeMirror, Monaco, ProseMirror/Tiptap and Quill separately using pinned public APIs/framework fixtures; list unsupported versions/cases.
2. Record focus/targets/extract/apply/commands as independent capabilities and consent scopes. Validate exact instance/revision conflict handling in isolated prototypes.
3. For any proposed apply path, test undo, formatting, selection, conflict and no-partial-mutation semantics; unknown result is no-go, not generic innerHTML/value writeback.
4. Produce per-framework go/no_go design reports. No Google Docs generic writeback or production downloaded adapter is authorised.

## Do not do
No public feature or full framework support claim from emulated fixtures, no guessed private APIs and no forced flattening/collaborative rollback.
