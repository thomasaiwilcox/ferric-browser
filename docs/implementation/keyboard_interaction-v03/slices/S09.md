## Implementation order
1. Establish exact document-generation semantics and supported event ordering for History API, fragment changes, reload, redirects and true document replacement.
2. Add tests before changing the baseline reset policy. Preserve only user-entered persistent pass-through on positively proven same-document changes.
3. Keep Pass Next Key stricter cancellation, re-evaluate Mixed route policy before new gestures, and reject stale callbacks.
4. For ambiguous/public-API-unsupported cases retain baseline reset and report capability unavailable; no URL-only or same-origin shortcut.

## Do not do
Do not preserve mode across a true navigation, auto-enter pass-through from a role/URL, or rewrite Insert focus policy for convenience.
