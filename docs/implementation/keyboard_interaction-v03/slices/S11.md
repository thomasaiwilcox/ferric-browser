## Implementation order
1. Add internal typed per-family selector entries and a prepared-configuration operation that keeps active config/persistence unchanged until complete validation.
2. Use the installed WebEngine CSS parser on a small browser-owned local document; validate all strings with config generation/timeout ownership.
3. Implement stale/failure/unavailable/startup handling and full-versus-structure-only CLI validation outcomes.
4. Do not publish final selector settings until S12 integrates matching; ordinary config without new selectors must retain the existing validated path.

## Do not do
No regex CSS parser, main-page parser callback as policy authority, Qt dependency inside the pure config crate, partial commit or premature runtime override persistence.
