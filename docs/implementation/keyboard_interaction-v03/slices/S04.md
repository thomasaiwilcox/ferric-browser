## Implementation order
1. Implement explicit highlight/Enter-confirmed Pointer click through the existing adapter; preserve full entry/confirmation gesture ownership.
2. Build exact retained-target preflight, clipped hit point, host expiry, owner/config/surface checks and qualified coordinate mapping. One request and one transport only.
3. Handle rejection/uncertain/receiver-gone terminal paths and map cleanup; expose bounded outcome wording, not application-success claims.
4. Run pointer-only and normal control tests plus adversarial changes before and after preflight. Record the unobservable race and actual user-activation outcomes.
5. Enable the explicit command/palette action only on supported configurations; no default hint strategy change.

- **T011 — Pointer-only custom control:** Explicit pointer action produces the qualified move/down/up/click sequence once; default semantic click is unchanged; no fallback double activation. Evidence: native-qt-offscreen, native-wayland.
- **T012 — Native activation regression types:** Links/target blank, regular buttons, inputs, contenteditable, open roots and same-origin frames retain default actions; explicit pointer never also runs URL or DOM transport. Evidence: native-qt-offscreen.
- **T013 — Pointer preflight races and expiry:** Reject observed owner/config/surface/overlay changes and expired preflights; stress the unobservable interval and document residual uncertainty, never claim atomicity. Evidence: webengine-fixture, native-qt-offscreen.
- **T014 — Engine activation restrictions:** Observe isTrusted and allowed/denied fullscreen/popup/clipboard/chooser outcomes without altering engine permission policy; no general trust claim. Evidence: native-qt-offscreen, native-wayland.
- **T020 — Operation/map lifetime and handoff:** No hint-map destruction before callback; acquire destination lease before source cleanup; weak refs, observers and callbacks terminate exactly once. Evidence: webengine-fixture.
