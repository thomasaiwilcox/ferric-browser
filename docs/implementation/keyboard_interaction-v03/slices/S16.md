## Implementation order
1. Add local target-search grammar and explicit text-mode entry reusing HintInteraction/ranking; do not create new matching semantics.
2. Build visible-only native result presentation and scoped entry with exact-ID deduplication and shared action palette.
3. Keep query private/ephemeral; coalesce refresh, clear explicit selection when identity/action meaning changes and require Enter confirmation.
4. Prove links/controls/regions/surfaces, virtualised replacement, no offscreen promise and local-only native-action provenance.

## Do not do
No durable universal-switcher target cache, second fuzzy matcher, auto-activate-on-one-match, arbitrary URL-from-label action or list-index retargeting.
