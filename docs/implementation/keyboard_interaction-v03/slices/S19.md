## Implementation order
1. Write the narrow native double-click ADR/state extension and qualify actual public Qt/DOM event ordering in a disposable fixture.
2. On positive proof, expose only an explicit local Grid/palette action with existing owner/expiry/deduplication rules; no default key remap.
3. Test cleanup, uncertain dispatch, navigation and no duplicate URL/DOM transport. Record supported engine/platform.
4. On no-go, keep capability unavailable and report the concrete boundary; do not manufacture events in page JS.
