## Implementation order
1. Inventory actual observable native prompt/menu lifecycles. Add ephemeral owner-bound leases only for those hooks; keep in-page DOM modal handling separate.
2. Capture saved mode and expected post-suspension epoch; implement depth-eight LIFO nesting and safe out-of-order/stale completion handling.
3. Cancel target UI/one-shot restoration, preserve real Qt input, and restore supported editing/persistent mode only to unchanged owner/focus/config.
4. Expose category/unknown state in context projection and qualify keyboard-only chooser accept/cancel/deactivation/tab-switch journeys.

## Do not do
No timers pretending to identify native dialog completion, guessed focus restoration, synthetic keyboard releases, target-UI resurrection or new persistent context authority.

## Tests and evidence
- **T024 — Physical gesture regression:** Native keydown/up, repeats, overlaps, entry-key isolation, lost releases, delayed WebEngine copies and epoch changes never double-dispatch or become a new browser command. Evidence: native-qt-offscreen.
- **T025 — Escape, mode labels and primary/secondary parity:** Existing Ctrl+v/Ctrl+Shift+v/;v/i/I and recovery/emergency semantics plus both window status/help surfaces remain correct. Evidence: qml-component, native-qt-offscreen.
- **T028 — Native prompt leases and nesting:** Keyboard-only chooser accept/cancel and supported nested prompts restore only the matching suspended epoch/owner; native input is not stolen by Mixed policy. Evidence: native-qt-offscreen, native-wayland.
- **T029 — Prompt stale completion and one-shot cancellation:** Tab/document/config/manual-mode change invalidates restoration; out-of-order completions fail safely; never resurrect Hint/Grid/Pass Next Key. Evidence: native-qt-offscreen.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.
