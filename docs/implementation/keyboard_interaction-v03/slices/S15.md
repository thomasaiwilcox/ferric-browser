## Implementation order
1. Separate ViewLocal viewport/interaction/current rectangles in the core; explicitly support nonzero scope origins while preserving legacy viewport invariants.
2. Qualify CSS/frame-to-Qt conversion, borders, zoom, scale and window offsets through the existing native adapter; reject unsupported transforms.
3. Wire local palette scope lease, geometry tolerance and surface/owner/config checks; scope-specific reset/hover/history behaviour follows C15.
4. Run scaled native and cross-origin-exterior journeys; document canvas/repaint/race limitations rather than cancelling every repaint.

## Do not do
No QML-only overlay mask, CSS/DIP conflation, double DPR scaling, remote palette loophole or semantic guarantee for moving canvas internals.

## Tests and evidence
- **T010 — Local pointer/scoped entry provenance:** Local physical UI handoff works; IPC, CLI, aliases wrapping remote calls, macro/repeat/userscript/generic action-executor paths cannot mint or replay permits. Evidence: pure-unit, native-qt-offscreen.
- **T035 — Cross-origin/closed-root boundaries:** Only outer iframe/surface is inspectable by parent; semantic within rejects; explicit raw native Grid is separately qualified; no false child semantic support. Evidence: webengine-fixture, native-wayland.
- **T036 — Scoped registry lease transfer:** Source session retains records until destination weak scope lease validates; cancellation/replacement clears without leaks; one page-target session per window. Evidence: pure-unit, webengine-fixture.
- **T038 — Scoped Grid coordinate spaces:** Nonzero scope, nested borders, zoom, DPR and window offsets map exactly once into ViewLocal coordinates; reject unsupported transforms instead of guessing. Evidence: pure-unit, native-qt-offscreen, native-wayland.
- **T039 — Grid scope lifecycle and hover:** 0/Backspace/Space reset within scope; reflow/owner/config changes invalidate; ordinary repaint does not cancel; full-view Grid regression remains. Evidence: native-qt-offscreen, native-wayland.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.
- **T055 — Registry/CLI/IPC/resource documentation parity:** New arguments/settings/help and invalid combinations agree across registry/codecs/runtime; local-only paths reject remotely; manifests/hashes/docs regenerate cleanly. Evidence: pure-unit.
