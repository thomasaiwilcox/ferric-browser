## Implementation order
1. Implement/test internal typed browser-first/mixed exact single-key policy and effective layering using existing logical key canonicalisation.
2. Freeze reserved keys, limits, duplicate handling and replace-list semantics from C10; define prefix/count outcomes and diagnostic provenance.
3. Keep this preparation internal until S08 wires and publishes the setting. Do not accept a user-visible setting that would be silently ignored.
4. Add tests for logical-versus-native identity distinction, layout/AltGr representations and unknown tokens; leave native event routing untouched.
