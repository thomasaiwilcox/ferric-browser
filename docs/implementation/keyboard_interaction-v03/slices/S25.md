## Implementation order
1. Create a fixed candidate corpus and compare current labels plus text search with numeric/scattered/word-derived prototypes outside production defaults.
2. Measure gestures/time/errors/refresh churn and determinism/prefix-free output; label simulated keystroke results separately from real user observations.
3. Apply C21 evaluation trigger and document the result, including no benefit. No default or production strategy switch is part of this slice.
4. Keep sensitive values out of word candidates and preserve rapid/text-search/refresh contracts.
