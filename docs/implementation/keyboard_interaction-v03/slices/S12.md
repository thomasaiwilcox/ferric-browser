## Implementation order
1. Publish seven-family extend/replace settings with final count/byte limits and the existing rule precedence.
2. Apply effective family policy to all discovery passes; empty replace must disable that family including implicit secondary additions.
3. Capture discovery provenance/config revision and apply the same effective policy at fresh/final validation. Preserve semantic type/action guards.
4. Invalidate active target/scope/preflight sessions on config change; add positive custom-control and invalid syntax/layering/resource tests.

## Do not do
No new region/proxy selector language, arbitrary JS values, hint selector granting native/proxy authority or hard-coded default all check after a configured discovery.

## Tests and evidence
- **T009 — Typed candidate payload and safe labels:** Reject malformed IDs/geometry/extra authority fields; no control value, password, secret hidden buffer or HTML executes/leaks through labels. Evidence: pure-unit, webengine-fixture.
- **T030 — Selector prepare/validate/commit:** Malformed CSS, unavailable engine, startup, stale validation callback and invalid runtime persistence leave the full old effective config intact; no regex-only success. Evidence: pure-unit, webengine-fixture.
- **T031 — Selector layering and disabled families:** Global/profile/site extend/replace, empty replace, 16/32-selector and byte limits, rule order and default all independence match C09. Evidence: pure-unit, webengine-fixture.
- **T032 — Custom selector fresh/final policy:** Added custom target remains eligible through fresh/final action using captured policy; removed policy cancels; invalid kinds never gain URL/proxy/native capability. Evidence: webengine-fixture.
- **T033 — Selector/traversal resource stress:** Large/dynamic roots and expensive selectors expose bounded/truncated status; caps do not pretend synchronous CSS evaluation can be interrupted. Evidence: webengine-fixture, performance.
- **T045 — Whole legacy interaction regression:** Existing hints/rapid/counts/caret/search/macros/Grid/scroll/Insert/pass-through tests remain; new capability restrictions do not delete legacy legitimate paths. Evidence: pure-unit, webengine-fixture, native-qt-offscreen.
- **T055 — Registry/CLI/IPC/resource documentation parity:** New arguments/settings/help and invalid combinations agree across registry/codecs/runtime; local-only paths reject remotely; manifests/hashes/docs regenerate cleanly. Evidence: pure-unit.
