# F01 — Register typed feature settings and apply atomically

**Lane:** core · **Type:** implementation · **Requirement:** EF-F01
**Dependencies (accepted, not just coded):** F00
**Exclusive locks:** config-registry, application-config
**Contracts:** C01, C13

## Outcome and work order

1. Register the exact scopes and apply boundaries for the typed settings; generate their help metadata in the existing configuration reference.
2. Apply a combined configuration update atomically. Invalid values must not partially persist or publish.
3. Preserve the model boundaries: `tabs.presentation` is startup/restart-scoped, `performance.hot_tab` and `hyprland.page_grouping` are live-scoped, and `passkeys.phone` takes effect for the next eligible document.
4. A requested setting alone does not establish capability availability. Runtime consumers provide effective state and proof through F01b.

## Allowed product paths

- `crates/ferric-browser-config/src/settings.rs`
- `crates/ferric-browser-config/src/runtime_config.rs`
- `crates/ferric-browser-application/src/configuration.rs`
- `crates/ferric-browser-application/src/configuration_write.rs`

The generator may update `docs/user/configuration.md`; do not edit that file manually. The eight-file product cap applies to product source, and this slice changes at most four product files.

## Acceptance case

**T010 — Atomic rejection (unit).** An invalid combined update does not partially activate any feature.

## Verification and handoff

Use the `config` recipe in `TESTING.md`. Bind T010 to an executable test and capture exact source SHA/tree, invocation, exit status and log digest using `tools/run_gate.py`. Do not run Cargo/build gates until the coordinator registers an external build target. Preserve the existing settings-draft/error UX and all security gates.

Return `templates/WORKER_RESULT.json` (<=6,000 UTF-8 bytes) with changed paths, candidate SHA/tree, test-to-receipt mapping, risks and integration notes. Worker status is `submitted`, never `accepted`; coordinator integrates only after independent review and reruns exact-source gates.
