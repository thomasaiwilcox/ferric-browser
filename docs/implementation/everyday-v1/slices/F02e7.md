## Outcome and steps

1. Migrate secondary, popup and auxiliary composition to the same public ownership model; capture source/page/profile/window at creation and preserve real popup WebContents adoption.
2. Route close/transfer through once-only owner retirement; remove dependencies on retained source views and private Quick delegate metadata.
3. Test foreground/background opens, nested popups, primary/secondary source closure, profile isolation, replacement hosts and child-before-parent/parent-before-child shutdown.
