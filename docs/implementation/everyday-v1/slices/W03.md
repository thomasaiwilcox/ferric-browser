**Lane:** presentation · **Type:** implementation · **Requirement:** EF-W03
**Dependencies (accepted, not just coded):** W02
**Exclusive locks:** command-dispatch, window-host
**Contracts:** C09, C12

## Outcome and work order

1. Implement same-scope fallback order for ungrouped windows while retaining existing tab commands/custom bindings.
2. Close exactly the page via current beforeunload/download decisions; preserve user drafts and last-close setting.
3. Keep pin as browser protection, restore existing recoverable metadata on undo and never claim unavailable DOM/POST restoration.
4. Handle targets disappearing after command issue and late close responses without acting on a replacement.
