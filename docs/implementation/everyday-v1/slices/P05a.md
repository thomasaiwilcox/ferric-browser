# P05a — Implement native helper process supervision substrate

**Dependencies:** P01, P02 · **Acceptance:** T061a

## Outcome

1. Reuse the existing CXX-Qt/native build boundary and add actual production-compiled QProcess supervision with immutable per-launch owner/incarnation tokens and private bounded stdin/stdout/stderr pipes. No second browser/runtime, shell, PATH search, page-controlled executable/arguments or ceremony secrets in argv/environment.
2. Production launch resolves only its packaged helper. Fake helper path/interpreter/mode authority is internal native test-only authority constructed by the harness, never a QML/page-settable path/property/environment fallback and never native-origin/phone qualification. Keep fixture modes fixed and secret-free in arguments.
3. Implement bounded framing, buffer/resource limits, asynchronous start/error/finish handling and owned cancel/terminate/kill/reap. Never block the GUI thread; late callbacks and output after terminal/cancel cannot affect a successor. Raw helper frames stay internal; no raw stdout/stderr/QR/challenge/credential bytes in ordinary diagnostics/exports.
4. Provide the narrow internal frame-validation/terminal acknowledgment boundary needed by P05b. Full strict v1 Rust message interpretation, QR dimensions/progress semantics and application routing belong to P05b; this component does not inherit or replace T061-T063.
5. Add exact CTest everyday_T061a_helper_supervisor_component selecting QtTest slot helperSupervisor in tests/everyday/tst_credential_process.cpp. Link/use the current Cargo-built production supervisor via the existing application/everyday harness; no copied model or fake process implementation. Execute real owned fake subprocesses through framing/start/crash/truncation/oversize/cancel/reap/stale-callback cases, including an unrelated sentinel child that must survive cancellation.
6. Preserve all current CTest registrations, SDK/security guards and original P05 requirements. Capture exact production source/build/test/binary and fixture hashes with zero-skip executable evidence. This is component evidence, not composed application, actual native origin, transport, signature or phone qualification.

## Scope and gates

Exactly six writable plan paths; named locks and exact overlap remain exclusive. Shared everyday CMake registration is serial across both children and any other owner. No subagents, extra paths/dependencies, copied models, assertion removal, security/default/SDK weakening, global profile/config/trust changes, real accounts or native/physical claims. Report a real amendment/split if a required boundary does not fit; do not invent an alternate unchecked route.

Run focused assigned actual production tests under a coordinator-owned build lease; no second native pipeline. Candidate source review, serial integration and fresh exact integrated tests/final review precede acceptance. Return WORKER_RESULT<=6000 bytes with exact SHA/tree, case/receipt/log/binary bindings and missing proof. All original P05 application cases remain required in P05b.
