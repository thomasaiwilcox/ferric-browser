## Outcome and work order

1. Install versioned browser-owned resources through the existing build/hash mechanism and reserved-world rules.
2. Keep native function references and exact request/signal semantics; bridge only eligible explicit publicKey operations.
3. Implement bounded BufferSource/JSON conversion, correct byteOffset/byteLength handling and closed messages.
4. Capture trusted facts only in mediator/native handshake. Reject iframe-origin authority and unknown schema versions.
5. Non-public-key and unsupported phone contexts keep native operation rather than being globally overwritten.
