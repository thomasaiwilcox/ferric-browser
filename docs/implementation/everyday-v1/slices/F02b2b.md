## Outcome

Resolve or precisely classify the QtWebEngine hover crash observed after the real transfer reserve is created, through a separately registered test focused on reserve preservation and event delivery.

## Work order

1. Reproduce the exact prior crash context on the qualified Qt 6.11.2 application harness: a real nested Qt popup/opener and source identity, followed by the production reserve call that returned true with Component Ready and no QML warnings before the prior T014 process crashed.
2. Trace Qt Quick/WebEngine view, delegate, popup host and reserve ownership to find a reproduced product or test-fixture cause. The recorded stack passes through `RenderWidgetHostViewQtDelegateItem::hoverMoveEvent`, Qt Quick hover/update delivery and `ApplicationTests::page/productPolishPopupCommands`; the optimized binary lacks an exact source line.
3. Split reserve creation and its post-creation lifecycle into a distinct QtTest slot and exact CTest case `everyday_T014b_transfer_reserve_hover_preservation`. Preserve every original reserve assertion: successful creation; non-null/distinct/hidden reserve; tab index -1; original popup remains active; URL/history/page state remain unchanged; cleanup succeeds. The gate must complete hover/update delivery without a crash.
4. Do not mask the crash by disabling hover/input, weakening event handling or assertions, skipping, retrying the old monolithic T014 case, or converting the positive reserve to null. Do not recreate a page from URL or add permissive fallback behavior.
5. Repair only a demonstrated defect within the seven listed existing paths. If a reproduced issue is confined to the available Qt/offscreen environment and cannot be resolved in scope, return a precise `blocked_environment` result with evidence.
6. Keep T014b registered and non-skipping. After fresh source review and the coordinator build lease, run exact T014b with zero skips plus discovery and affected T014a, T013 and T015 regressions on the same integrated source. T014a remains a separate child acceptance; all three cases are regressions for this child.
