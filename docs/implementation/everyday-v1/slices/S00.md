## Outcome and work order

1. Follow START_HERE; use bootstrap for a fresh clone or a clean explicitly provided checkout. Verify remote identity before executing repository-supplied code; never read credentials or live browser data.
2. Fetch origin/main; compare with pack authoring SHA and proposal SHA. Inspect applicable instructions and current branches/worktrees without merging other work.
3. Resolve every named source anchor locally; classify each as existing, renamed, removed or proposed. Record already-implemented prerequisites, especially secondary hints/profile ownership.
4. Read current SDK manifest/build.rs/CI and map shared-state owners and credential/script worlds. Produce an approved source map and lock amendment for moved files.
5. Freeze execution baseline, environmental limitations and branch policy. No product code in this task.
