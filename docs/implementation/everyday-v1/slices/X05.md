1. Follow RESOURCE_POLICY dry run; retain source/commits/evidence and delete only inactive explicitly owned build products.

**T160 — Owned cleanup only (inspection).** Source, .git, logs, dependency locks and unrelated sentinel directories are unchanged by cleanup.

**T161 — Reproducible rebuild (build).** Clean owned build products regenerate the correct current production library/helper.

**T162 — No stale artifact testing (application).** Integrated tests identify and exercise the rebuilt candidate, not a previous worktree artifact.

## Verification

Use the `rebuild` recipe in TESTING.md and bind the case IDs above to real executable assertions or the specified external evidence. S01 must register added native/application suites before invocation. Inspect discovery output; no zero-test, skipped-only or timeout result is accepted. Run focused tests first and the affected current regressions after the change. Capture the exact source SHA/tree, environment, invocation, exit status and log digest through tools/run_gate.py where applicable.

For inspection/setup tasks, the concrete output is a reviewed map/report with reproducible checks, not a claimed runtime pass. For native/physical tasks, absence of equipment is a blocker, not permission to relabel a mock as native evidence. Any production positive path needs observable execution, not only source-string assertions or rejected-input tests.
