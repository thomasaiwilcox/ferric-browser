## Outcome and work order

1. Locate current schema/recovery APIs before extending optional presentation and logical grouping hints.
2. Never persist native addresses, live leases, spare state or credentials. Preserve older sessions and back up before any required schema change.
3. Keep private data nonpersistent and unknown group hints ignorable without discarding pages.
4. Do not reimplement the current lazy restored-tab and last-tab-undo logic from an outdated proposal.
