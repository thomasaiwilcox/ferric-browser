# F02e1 — Implement public profile and page ownership

**Parent:** F02e · **Requirement:** EF-F02 · **Amendment:** A37

**Dependencies:** F02e0

## Outcome and steps

1. Implement explicit QWebEngineProfile and QWebEnginePage owners using public APIs, separate from presentation widgets; profile lifetime covers every page and active request.
2. Own page/document/host generations; close invalidates pending callbacks and destroys the browsing context exactly once. Never retain a live closed opener to satisfy a native anchor.
3. Test actual production owners: same-profile adoption, cross-profile rejection, delayed callbacks, true source close with surviving descendants and shutdown/drain. This replaces T014c lease-mechanism coverage, retaining ownership and resource invariants.
