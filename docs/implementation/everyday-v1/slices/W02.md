# W02 — Create single-page native hosts using existing workspaces

**Lane:** presentation · **Type:** implementation · **Requirement:** EF-W02
**Dependencies (accepted, not just coded):** W01, F02, F04, F05
**Exclusive locks:** window-host, primary-shell, secondary-shell, page-factory, build-registration
**Contracts:** C01, C09

## Outcome and work order

1. Instantiate a reusable one-page host with current HintWorkspace/PageSearch/modal/appearance services; no copy of the entire browser shell.
2. Hide only irrelevant tab strip; preserve privacy header, status/command and close/undo safeguards.
3. Register exact host/page identities and shared profile resources; do not spawn a browser process for each page.
4. Support generic Wayland without Hyprland and survive closure of original visible host.
