## Outcome and work order

1. Use the pinned library’s actual QR-initiated hybrid API for both create and get; do not implement protocol crypto.
2. Report bounded QR and closed progress states; use library transient-device mode, not remembered-pairing persistence.

4. Do not automatically replay an uncertain create. Document retry handling only for explicitly safe device responses.
