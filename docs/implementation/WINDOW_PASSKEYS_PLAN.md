## Architecture and safety decisions

Keep internal tabs as the default. Window presentation, phone passkeys and compositor grouping are opt-in. The public Widgets owner/scene remains an alternative prototype; completing a Widgets backend migration is not required. Reuse one captured engine-request consumer and the actual Quick profile/view/native-window lifetime registry.

The notification-only channel in reserved world 42 supplies no page-controlled origin, owner, target or result destination. Native main-frame challenges, exact native presentation and actual Core/profile leases establish authority. Native provider choice owns focus. Installed interceptor ownership and nonwrapping policy generation revoke stale work, including changes from sibling windows. Queued document continuations must retain their original Core Target across asynchronous window selection.

Phone transport initially permits only effective policy-approved direct networking. Proxy, offline, unsupported or restrictive routes disable phone admission before connection. The helper uses assigned pinned relays, checked public sockets, normal original-host TLS and Bluetooth proximity; no proxy bypass, redirect, replay, remembered-device or PIN storage. Preserve existing Qt authentication for unsupported requests and native provider choice.

The native adapter checks the exact installed profile interceptor before submission, during the ceremony and before delivery. Relay security-deny and host rules remain effective. General ABP path filters are currently unsupported for phone transport unless the requesting site already has a configured bypass: the adapter cannot prove every fresh relay path is permitted and does not change blocking policy. System-proxy resolution and unsupported resolver overrides likewise decline phone use. Native bootstrap now snapshots Qt-effective flags before profiles are created and rejects subsequent flag changes. One exact captured-RP-host mapping to 127.0.0.1 is admitted for scoped HTTPS fixtures; wildcard, relay-host, extra-rule, port-pattern and other DNS overrides remain denied. The current routing and teardown checks pass. These conservative limits must remain visible in final qualification; they are not permission to bypass policy for a device test.

Keep durable session data normal-profile-only, safe to restore and bounded. Restore metadata describes unpresented pages; an actual presented window's current context takes precedence. Aggregate writes require capture-time ordering that survives per-owner queues and cannot let delayed old snapshots overwrite newer ones. Preserve prior valid generations on failures.

## Live-transfer integration decisions

Presented transfer uses a separate native-only capture, preserving the full page state and precise zoom while remapping the destination Core window/profile IDs. The native lifetime lease excludes ordinary adoption, popup and credential consumers during staging. Navigation, loading, renderer or lifecycle changes invalidate it; actual owner retirement defers destruction until the transaction ends. Its shared internal state survives destruction of the caller's adapter/handle. A stable raw key is used only to erase the exact registry entry after the guarded view is destroyed. Rollback creates a fresh native incarnation and must never restore an old credential/prompt lease.

The remaining adapter must reserve a hidden unpublished child, retain the original factory/context, remove the captured old prompt association before changing routing, and guard model/IPC/session/grouping publication throughout staging. Final actual-view/profile/window checks and both typed Core mutations must run in one native entry point with no return through QML between proof and commit. Native lifecycle facts during staging must invalidate or be replayed safely, not silently disappear.
