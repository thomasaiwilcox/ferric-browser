# Code of conduct

Contributors are expected to be respectful, specific, and collaborative.
Harassment, discrimination, intimidation, doxxing, credential disclosure, and
deliberate exposure of another person's private browsing or account data are
not acceptable.

Report conduct concerns privately to the project owner through the same
maintainer-controlled route used for sensitive project reports. Do not publish
private evidence or personal data in an issue. Until a project contact route is
published, retain sensitive details locally rather than placing them in public
channels.
